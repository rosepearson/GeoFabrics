.. py:class:: BaseProcessor(json_instructions)

   Bases: :py:obj:`abc.ABC`


   An abstract class with general methods for accessing elements in
   instruction files, including populating default values. It also contains
   functions for downloading remote data through geoapis and constructing data
   file lists.

   The `BaseProcessor` class contains several important class members:
    * instructions - Defines the pipeline execution instructions
    * catchment_geometry - Defines all relevant regions in a catchment required in the
      generation of a DEM as polygons.
    * logger - logging within this class

      the key is not in the instructions.

   .. py:method:: get_lidar_datasets_info()

      Return LiDAR file paths and their optional CRS and tile index as a
      dictionary. Extract this information from the instruction file as well
      as any API responses.

      ``file_paths`` contains the LiDAR tiles to process. The optional
      ``crs`` value is the EPSG code to use when the source files do not
      contain valid CRS information; explicit CRS values are currently
      supported only for OpenTopography LiDAR. The optional
      ``tile_index_file`` describes tile extents and is currently supported
      only for OpenTopography files.

      When a LiDAR dataset is specified through an API or local source,
      collect its files within the catchment. Otherwise, read the ``lidars``
      entry from ``data_paths``.

   .. py:method:: calculate_river_bed_elevations()

      Estimate and save river-bed elevations using two depth methods.

      Reads the saved channel-characteristics layer, associates each row with
      the nearest river-network reach, and estimates bed elevations using
      the Neal et al. uniform-flow and Rupp and Smart hydraulic-geometry
      methods. The resulting elevations and channel attributes are written
      to the configured river-bathymetry result file. When debug output is
      enabled, the full-bank and area-adjusted depths are included as well.

      :returns: Writes the estimates to disk; no result is returned.
      :rtype: None

      .. rubric:: Notes

      Missing reach IDs, flow, and Manning's n values are filled forward and
      backward from neighboring rows. Other missing or invalid inputs are
      not explicitly imputed and may propagate into the estimates. Negative
      depth estimates are set to zero, and depths below the configured
      threshold are raised to that threshold. Flow is in m^3 / s, width is
      in meters, slope is dimensionless, Manning's n is dimensionless, and
      elevations are in meters.

      Calculate and save depth estimates along the river mouth fan.
