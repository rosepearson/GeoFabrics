interpolate_ocean_chunked(ocean_points, cache_path, k_nearest_neighbours, use_edge, buffer, method)

Interpolate offshore elevations into the current DEM in chunks.

Point data are rasterized over areas without dense DEM data. When use_edge is true, samples from the foreshore/offshore boundary are included to constrain the interpolation. The DEM is updated in place. The point data should have the same vertical datum and units as the DEM. Typically if the point data is in MSL (mean sea level), it will be close enough.

Parameters:

  • ocean_points – Ocean bathymetry point collection to interpolate.

  • cache_path (pathlib.Path) – Directory for temporary point-cloud files.

  • k_nearest_neighbours (int) – Number of nearest samples used by the selected interpolation method. Offshore interpolation is skipped when there are too few ocean or edge points.

  • use_edge (bool) – Whether to include samples from the foreshore/offshore boundary.

  • buffer (int) – Width of the exclusion buffer around land and foreshore, in units of catchment grid cells.

  • method (str) – Method passed to point_elevation(), such as mean, median, idw, linear, cubic, nearest, or rbf.

Returns:

Updates the DEM in place.

Return type:

None

Parameters:

  • method (str) – Interpolation method: rbf, linear, cubic, or nearest.

geofabrics.dem.roughness_from_points(point_cloud, xy_out, xy_ground, options, eps=0, leaf_size=10)

Estimate roughness values at query locations from nearby point heights.

For each query, calculate the mean height above ground and the point-height standard deviation within options["radius"]. Return the greater of std * options["parameters"]["std"] and height * options["parameters"]["mean"].

Parameters:

  • point_cloud (numpy.ndarray) – Structured point array with X, Y, and Z fields.

  • xy_out (numpy.ndarray) – Query coordinates with shape (n, 2).

  • xy_ground (numpy.ndarray) – Ground elevations corresponding to xy_out; must have length n.

  • options (dict) – Must contain radius, raster_type, and parameters with std and mean scale factors.

  • eps (float) – Approximation tolerance passed to the KD-tree radius query.

  • leaf_size (int) – KD-tree leaf size; affects query performance, not results.

Returns:

Roughness estimates with one value per query. Queries with no nearby points are set to NaN.

Return type:

numpy.ndarray

Notes

X/Y coordinates and options["radius"] must use the same planar coordinate units. Z and ground values must use the same vertical units. Non-finite point values are not filtered and may propagate to the result.

geofabrics.dem.elevation_from_nearest_points(point_cloud, edge_point_cloud, xy_out, options, eps=0, leaf_size=10)

Estimate elevations from the nearest points, optionally including edge points.

Parameters:

  • point_cloud (numpy.ndarray) – Structured array of interpolation points with X, Y, and Z fields.

  • edge_point_cloud (numpy.ndarray) – Structured array of nearby edge samples with the same fields.

  • xy_out – Query coordinates with shape (n, 2).

  • options (dict) – Must include k_nearest_neighbours, use_edge, raster_type, and the keys required by options["method"].

  • eps (float) – Approximation tolerance passed to each KD-tree query.

  • leaf_size (int) – KD-tree leaf size; affects query performance, not results.

Returns:

One elevation per query. Returns all NaNs when point_cloud has fewer than k_nearest_neighbours points, or when use_edge is true and edge_point_cloud has fewer than that number.

Return type:

numpy.ndarray

Notes

X/Y coordinates in both point sets and xy_out must use the same planar coordinate units. Z values are returned in their input vertical units. The primary point_cloud is always required; edge points supplement it only when use_edge is true. Thus, for positive k_nearest_neighbours, an empty point_cloud returns all NaNs even when edge points are available. Non-finite point values are not filtered.

geofabrics.dem.point_elevation(near_z, near_points, point, options)

Estimate one value from a query point’s neighbouring samples.

options["method"] selects mean, median, IDW, linear, cubic, nearest, RBF, minimum, maximum, standard deviation, or count. Interpolation methods require matching near_points and near_z entries.

Parameters:

  • near_z (numpy.ndarray) – Z values of the neighbouring samples.

  • near_points (numpy.ndarray) – Neighbour coordinates with shape (n, 2).

  • point (numpy.ndarray) – Query coordinate with shape (2,).

  • options (dict) – Method configuration. IDW uses the coordinates and values; griddata methods also use strict; RBF uses kernel.

Returns:

Scalar estimated value, or NaN when there are no neighbours.

Return type:

float

Notes

X/Y coordinates must use the same planar units. Most methods return Z values in the input vertical units; std returns a Z spread and count is intended to return the number of neighbours. ROSE TO DEFINE: Confirm handling of non-finite Z values, and whether count is a supported method.

geofabrics.dem.calculate_idw(near_points, near_z, point, smoothing=0, power=2)

Estimate a value using inverse-distance weighting.

An exact coordinate match returns that sample’s value. Otherwise, each value is weighted by the inverse of its smoothed distance raised to power.

Parameters:

  • near_points (numpy.ndarray) – Neighbour coordinates with shape (n, 2).

  • near_z (numpy.ndarray) – Values at near_points; must have length n.

  • point (numpy.ndarray) – Query coordinate with shape (2,).

  • smoothing (float) – Non-negative distance added in quadrature before weighting.

  • power (int) – Exponent applied to the distance weights.

Returns:

Weighted estimate in the same units as near_z.

Return type:

float

Notes

Coordinates, smoothing, and distances must use the same units. TO DEFINE: Confirm the intended units and allowed range for smoothing and power. This function expects at least one finite sample; it does not filter non-finite inputs.

geofabrics.dem.calculate_interpolate_griddata(near_points, near_z, point, strict, method)

Interpolate a query value from nearby points using SciPy griddata.

With one sample, return its value. With two samples, use inverse-distance weighting. With three or more, use the requested method. If the interpolation produces NaN, strict=False falls back to inverse-distance weighting.

Parameters:

  • near_points (numpy.ndarray) – Neighbour coordinates with shape (n, 2).

  • near_z (numpy.ndarray) – Values at near_points; must have length n.

  • point (numpy.ndarray) – Query coordinate with shape (2,).

  • strict (bool) – If true, preserve a NaN result; otherwise use the distance-weighted fallback when possible.

  • method (str) – SciPy griddata method, typically linear, nearest, or cubic.

Returns:

Interpolated value, or NaN if there are no samples or the strict interpolation fails.

Return type:

float

Notes

All coordinates must use the same planar units. NaN input values are not explicitly filtered. TO DEFINE: Confirm behavior for non-finite coordinates/values and whether the two-point fallback should handle a query exactly on a sample.

geofabrics.dem.calculate_rbf(near_points, near_z, point, kernel)

Estimate a query value using SciPy’s radial-basis-function interpolator.

For three or more samples, fit an RBF interpolator using kernel. If fitting fails or there are fewer samples, fall back to cubic griddata interpolation (which uses the one- or two-sample behavior documented by calculate_interpolate_griddata()).

Parameters:

  • near_points (numpy.ndarray) – Neighbour coordinates with shape (n, 2).
