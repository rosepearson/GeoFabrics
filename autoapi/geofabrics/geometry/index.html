class geofabrics.geometry.CatchmentGeometry(catchment_file, crs, resolution, foreshore_buffer=2)

Define catchment regions as polygons.

The CRS is a dictionary containing the EPSG code for a ‘horizontal’ and ‘vertical’ datum.

This class defines the land, foreshore, and offshore regions and ensures that they use the same CRS.

The regions are clipped to the catchment and do not overlap. The land region is defined by a supplied polygon. The foreshore is an outward buffer from the land region, with width foreshore_buffer * resolution. The offshore region is the remaining area outside the land and foreshore.

The class also provides methods to exclude areas, such as LiDAR extents, from a region; see land_and_foreshore_without_lidar for an example.

Initialize the class with the catchment, then set the land region before accessing the other regions.

sample_contours(resolution)

Sample contour lines at regular intervals.

Parameters:

resolution (float) – Positive spacing between samples, in the horizontal coordinate units of the catchment CRS.

Returns:

Structured array with X, Y, and Z fields. Returns an empty list if there are no contours to sample. Sample locations are in the catchment horizontal CRS.

Return type:

numpy.ndarray or list

Notes

The stored Z values are multiplied by -1 whether they come from 3D contour coordinates or from z_label. Returned values define elevation in metres.

class geofabrics.geometry.RiverMouthFan(aligned_channel_file, river_bathymetry_file, river_polygon_file, ocean_contour_file, ocean_points_file, crs, cross_section_spacing, elevation_labels, ocean_elevation_label=None)

Create a fan-shaped transition from river-bed estimates or measurements to ocean depths.

The fan extends from the downstream-most river-width values to the first ocean contour deeper than twice the mouth depth. It provides a transition region slightly deeper than the surrounding bathymetry. A fan is calculated for each river-bed elevation approach. If the mouth width is unavailable, use the nearest upstream location with a valid width.
